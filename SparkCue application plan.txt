SparkCue application plan

```plaintext
Create a full Next.js app called "spark-cue" with built-in profile management and the following features:

0. Profiles:
   - Users can create, edit, delete “Profiles” representing each match or contact.
   - Each Profile includes: name, optional bio, optional location, structured picture descriptions (JSON), optional avatar image URL.
   - If no avatar URL is provided, display an embedded default SVG avatar.
   - ProfilesList component must display avatar, name, and preview of the most recent message.
   - ProfileDetail component must show profile info, full message history, and analytics charts per profile.

1. Message Generation:
   - For each Profile, generate opener messages using:
     • AI (OpenAI gpt-4-turbo or configured provider/model via ENV: AI_PROVIDER, AI_MODEL)
     • Automatic fallback to keyword templates from `/data/fallbackTemplates.json` (≥10 templates per persona) if AI unavailable.
   - Personas: Classy, Playful, Flirty, Adventurous, Intellectual, Sweet, Bold, Mysterious, Funny, Romantic.
   - Save each generated message linked to profile, with metadata: source (AI/Fallback), persona, timestamps, success, response latency.

2. Frontend:
   - Next.js, React, Tailwind CSS.
   - MessageForm (in ProfileDetail) with required: name (read-only), picture descriptions, persona selector; optional: bio, location.
   - Use React Hook Form for validation and sanitization.
   - Offline support: localStorage (web) and AsyncStorage (mobile) to cache profiles and unsent messages; sync when online.
   - Actions: Generate, Save, Mark Sent, Mark Responded; display generated message, metadata, and sync status.

3. Backend/API:
   - Next.js API routes with CORS enabled.
   - `/api/profiles`: GET, POST, PUT, DELETE CRUD operations.
   - `/api/messages/generate`: attempt AI generation; fallback to templates.
   - `/api/messages/add`: save generated message data.
   - `/api/messages`: list messages (filter by profile_id).
   - `/api/messages/update-status`: update sent/responded timestamps, compute latency.
   - `/api/analytics/time-of-day`: aggregate hourly engagement and success rates (global or per profile).
   - Future: `/api/billing`, `/api/admin/provider`.

4. Data/config:
   - `/data/fallbackTemplates.json`: JSON mapping each persona to ≥10 fallback templates using variables `${name}`, `${pictures[N].description}`, `${location}`.
